# Changelog

Each version is tagged in Git. The number shown in the app footer matches the tag.

## 1.1.0
- Works offline: the app opens without a connection, and changes sync when back online.
- App icon and install support (manifest) for Android and iPhone home screens.
- Version number shown in the footer and in Settings.
- Publishing now checks the app before it goes live.

## 1.0.0
- First version: home page of monthly transfers per account, entries, accounts, headings, and settings.
- Data pre-filled from the Excel budget workbook.
- Encrypted data saved to a private GitHub repository on every change.
